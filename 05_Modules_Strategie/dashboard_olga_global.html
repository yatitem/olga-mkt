📘 Guide d'Utilisation - Dashboard OLGA 1.0

Comprendre, Automatiser et Maintenir votre outil.

1. Vue d'Ensemble

Ce tableau de bord est votre cockpit de pilotage. Il centralise toutes les informations cruciales pour la prise de décision :

  • 📦 Catalogue Produit : Synchronisé en temps réel avec votre Google Sheet.
  • 🧺 Univers Linge : Analyse de marché, positionnement prix vs Isis/Ariel.
  • 🍋 Univers Cuisine : Stratégie Vaisselle & Dégraissant vs Pril/Force Express.
  • ✨ Maison & Hygiène : Opportunités Sols, Vitres et Savon liquide.

2. Automatisation & Robot de Veille 🤖

Le Dashboard intègre un Robot de Veille Concurrentielle (robot_veille.py). Son rôle est de mettre à jour les prix des concurrents (Isis, Omo, Force Express) dans les graphiques sans que vous ayez à toucher au code.

Comment lancer une mise à jour ?

  1. Méthode Manuelle : Allez sur l'onglet Catalogue, cliquez sur le bouton orange 🔄 Lancer Robot Veille Concurrents, et acceptez l'exécution du fichier .bat.
  2. Méthode Automatique : Si configuré, le robot se lance chaque Dimanche à 9h00 (via Tâche Planifiée Windows).

3. Maintenance & Images 📸

Pour ajouter une image, déposez-la dans Photos/OLGA PACKSHOT/ en respectant la nomenclature :

olga_[categorie]_[produit]_[format].jpg

Exemples :
olga_linge_bidon_10l.jpg
olga_vaisselle_750ml.jpg

4. Dépannage 🆘

  • Tableau vide ("Chargement...") ? Vérifiez votre connexion internet (accès Google Sheet nécessaire).
  • Image manquante ? Vérifiez le nom du fichier (minuscules, sans espaces) et son extension (.jpg).
